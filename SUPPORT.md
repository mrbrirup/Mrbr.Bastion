# Support

This source-only developer preview is intended for developers and controlled lab evaluation. It has no production support commitment or response-time guarantee.

Start with the [README](README.md), [configuration guide](CONFIGURATION-GUIDE.md), [retention reference](CACHE-RETENTION.md) and [known limits and roadmap](FUNCTIONALITY-AND-MVP.md). Use GitHub issues for reproducible non-security bugs and feature requests once the repository is public. Include the revision, exact SDK, affected component and a minimal synthetic reproduction.

Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Never post private keys, passwords, cookies, tokens, database files or real endpoint telemetry. Logs, paths, inventory versions and screenshots can identify a host even when no password is visible.

For collection/delivery problems, preserve the deployment's keys, databases and referenced archives before changing it. Record queue/source loss, pending age/count and maintenance errors using redacted summaries. Do not delete unsettled evidence to make an error disappear. The project cannot reconstruct events that were never captured.
